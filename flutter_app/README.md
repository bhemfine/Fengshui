# Inkstone — Flutter app (Android only)

Skeleton of the Ultimate Feng Shui app in the approved B3 look (midnight + champagne gold, twinkling starfield, Cormorant SC + Source Serif 4). All 21 prototype screens are wired with go_router and use **Example data only** (`lib/data/sample_data.dart`). No network, no billing, no storage yet.

- Android only: `android/` was generated by `flutter create --platforms=android`; `minSdk = 26` (Android 8.0), app id `com.inkstone.app` (change before first Play upload — it can never change after).
- Run: `flutter pub get` → `flutter run` (Android phone or emulator).
- Checks: `flutter analyze` → 0 errors, 0 warnings (only "material.dart is deprecated, use material_ui" infos introduced in Flutter 3.47+; migrate later). `flutter test` → 42/42 pass (every route builds on a 360×740 and 412×915 screen).
- Structure: `lib/theme` (tokens), `lib/motion` (durations, reduced-motion helper), `lib/widgets` (starfield, buttons, cards, tarot deck, HDB scan, score ring, star burst, transitions…), `lib/screens` (21 screens), `lib/router.dart`, `API.md` (widget reference).
- Reduced motion: every animation checks `MediaQuery.disableAnimationsOf` ("Remove animations" on Android).
- Next phases (see PLAN.md): plug in `../engine` as a path dependency, load `../content/*.json` as assets, add encrypted local DB (drift + SQLCipher, key in Android Keystore), proxy calls, Play Billing.

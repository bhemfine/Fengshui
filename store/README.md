# Inkstone: Google Play store and legal text

This folder holds the store listing and legal text for the Inkstone Android app. Inkstone is the working name. The final name is still an open decision.

| File | What it is |
| --- | --- |
| [listing.md](listing.md) | Name options, short and full descriptions, category, tags, content rating answers, screenshot captions, feature graphic text, v1.0 release notes |
| [privacy_policy.md](privacy_policy.md) | Privacy policy, PDPA-aware. Publish it at a public URL before the closed test. |
| [disclaimer.md](disclaimer.md) | Entertainment disclaimer: a short in-app version and the full text |
| [data_safety.md](data_safety.md) | Google Play Data safety form answers, plus a checklist to run before you submit |

## Placeholders to replace before publishing

- `[Publisher name]`: the legal name of the developer or company
- `[support email]`: the support contact address
- `[date]`: the effective date of each document
- `[privacy policy URL]`: the public URL where privacy_policy.md is hosted

## Notes

- Features marked "coming later" or "(later)" are not in v1.0. Keep the listing accurate for each release. Play may reject a listing that describes features the app does not have.
- Run the checks at the end of data_safety.md every time the app, the proxy or an SDK changes.
- These documents are drafts written in plain English. Have a qualified person review them for PDPA compliance before launch.
